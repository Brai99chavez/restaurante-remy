# Restaurante La Esquina (plantilla)

Landing de ejemplo para un restaurante de comida casera en La Plata.

## Qué es

Una plantilla para restaurantes que quieren recibir pedidos y reservas por WhatsApp. El nombre, el teléfono y la dirección son de ejemplo.

## Qué tiene

- Portada con botones para pedir por WhatsApp y ver el menú, destacados, la historia del lugar, platos del mes, el local y reseñas.
- Menú con precios: platos principales, pizzas y pastas, y bebidas.
- Galería de fotos.
- Ubicación con horarios, mapa de Google y cómo llegar.
- Menú adaptado al celular y botón de WhatsApp en todas las páginas.

## Tecnologías

HTML, Tailwind CSS y JavaScript, sin paso de armado.

## Cómo correrlo

```bash
git clone https://github.com/Brai99chavez/restaurante-remy.git
cd restaurante-remy
```

Abrí `index.html` en el navegador. Necesita internet para cargar Tailwind y las fuentes.
